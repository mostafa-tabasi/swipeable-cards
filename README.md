# Swipeable Cards

Swipe left, swipe right… just like in dating apps 😄

A fully customizable Swipeable Card Deck in Jetpack Compose:

- Drag & swipe the top card

- Back cards animate forward smoothly

- Adjust spacing, scale, opacity, and number of visible cards

A small interactive playground for swipe gestures — fun to use and easy to reuse.
